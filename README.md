# 第2の脳スターターキット（いち式）

**新しい会話を開いても、Claude Code が「昨日の続き」から話せる箱**です。
Obsidian と Claude Code で使う、フォルダ1つ。中に、案内板（CLAUDE.md）・自分のことを書く1枚（about-me.md）・案件カードと日誌の雛形・AI社員1人目（writer）が、全部入っています。
自分の会社で72人のAI社員が毎日読んでいる箱を、そのまま小さくした形です。

> YouTube「AI超人のいち」— Obsidian × Claude Code で"忘れない第2の脳"を作る5ステップ の特典です。

---

## 使い方は3手（5分）

1. **入れる** — 上の緑の「Code」→「Download ZIP」で保存し、展開する。中の `second-brain` フォルダを、デスクトップなど好きな場所へ移す。
2. **開く** — Obsidian を起動し、「保管庫としてフォルダを開く」で `second-brain` を選ぶ。
3. **話す** — Obsidianで `Command + Shift + H`（Windowsは `Ctrl + Shift + H`）を押してターミナルを開き、`claude` と打ってから、こう打つ。

```text
昨日の続き、何だっけ
```

見本の案件カードを読んで「次の一手」から答えたら、つながっています。そのあと、あなたのことを5つ質問して `about-me.md` を書いてくれます。普段話す言葉で答えてください。

Codex の人は `codex` と打ちます。`AGENTS.md` を入れてあるので、同じ案内板を読みます。

**ターミナル・Claude Code・Codex がまだ入っていない人は → [install-obsidian-terminal.md](install-obsidian-terminal.md)**（入れ方の全手順）。今すぐ試すだけなら、Claude アプリの「Code」タブで同じ `second-brain` フォルダを選んでも、同じことができます。

## 動画のステップ1〜3で、もう箱を作った人へ

自分の `second-brain` に、このキットの `memory/`・`staff/`・`inbox/` の3フォルダをコピーしてください。`CLAUDE.md` は、このキットの「フォルダの地図」と「会話の終わりに」の2ブロックを、自分の案内板へ足せば同じになります。`about-me.md` は、自分のを残してください。

自分の箱に合わせて AI に作らせたい人は → [chat-version.md](chat-version.md)（貼るだけの文）

## 中身

| 場所 | 何か |
|---|---|
| `CLAUDE.md` | 案内板。Claude Code が起動時に必ず読む1枚（24行） |
| `AGENTS.md` | Codexの入口。「最初に CLAUDE.md を読む」の1行だけ |
| `about-me.md` | 自分のこと。雛形のままだと、AI が5つ質問して書き直す |
| `memory/cases/` | 案件カード。1案件1ファイル、「要約・いまやっていること・次の一手・待っていること」。いまの状態を上書き |
| `memory/daily/` | 日誌。1日1ファイル、起きたことを追記 |
| `staff/writer/` | AI社員1人目。`_RULE.md`（役割と読む順番）・`skills/x-post/SKILL.md`（手順書）・`output/`（成果物） |
| `inbox/` | 未整理の置き場 |

「状態（カード＝上書き）」と「物語（日誌＝追記）」を分けるのが、この箱が忘れない理由です。自分は一度、日誌を1つのファイルに書き続けて、多い日は1日15万字になり、AI が読み切れなくなって作り直しました。これは、その作り直した後の形です。

## 完成見本

実際に動かした記録 → [examples/](examples/)
見本の案件（A社）は架空です。`second-brain/` の中の見本ファイルは、書き換えるか消して使ってください。

## 安全に使うために

- パスワード・APIキー・お客さんの実名は、この箱に入れないでください。AI にも「書かない」と案内板で指示していますが、最初から入れないのがいちばん安全です。
- 箱の中身は、Claude Code が読み書きします。会社の機密を入れるなら、会社のルールに従ってください。
