新しい会話でも、
「昨日の続き」が通じる箱。

いち式「第2の脳スターターキット」。ObsidianとClaude Codeで使うフォルダ1つに、案内板（CLAUDE.md）・自分のことを書く1枚・案件カードと日誌の雛形・AI社員1人目（writer）が全部入っています。自分の会社で72人のAI社員が毎日読んでいる箱を、そのまま小さくした形です。

キットをZIPで保存中身を見る（GitHub）

まず、動いたところを見る

このキットを開いて、新しい会話で「昨日の続き、何だっけ」と聞いた時の、Claude Codeの返事です（2026-11-03・手直しなし）。

結論：続きは「A社のホームページ作り直し」の見積もり作りです。

案件カードの「次の一手」はこの2つです。

- あなた：来週火曜（2026-11-10）までに見積もりをA社に出す。

- AI（私）：要件3つ（トップページ作り直し・お問い合わせフォーム・スマホ対応）を作業項目と金額に分けた見積もりの下書きを作り、80万円に収まるか確認する。

前提として、予算はだいたい80万円、公開希望は来月末（2026-12-31）です。A社からの返事待ちは今はありません。

もう1つ、日誌に小さな持ち越しがあります。writer（X投稿を書くAI社員）が打ち合わせ後の投稿を3案書いていて、どれを出すかあなたの選択待ちです。ファイルは `staff/writer/output/2026-11-03_打ち合わせ後のAI社員_X投稿3案.md` にあります。

なお、このカードは「見本」と書かれた架空の案件です。本物の案件に書き換えて使う前提なら、そう言ってください。

それと、`about-me.md`（あなたのことを書く1枚）がまだ雛形のままなので、5つだけ順に質問させてください。

1つ目：お仕事は何ですか？（業種や、ざっくり何をして稼いでいるか、で大丈夫です）

案件カードを作らせる所から、AI社員に頼む所までの全記録を読む

見本の案件（A社）は架空です。

使い方は3手（5分）

  1. 入れる — 上の「キットをZIPで保存」で保存し、展開する。中の second-brain フォルダを、デスクトップなど好きな場所へ移す。
  2. 開く — Obsidianを起動し、「保管庫としてフォルダを開く」で second-brain を選ぶ。
  3. 話す — Claudeアプリの「Code」タブで同じ second-brain フォルダを選び、下の文を打つ。
昨日の続き、何だっけ

見本の案件カードを読んで「次の一手」から答えたら、つながっています。そのあと、あなたのことを5つ質問して about-me.md を書いてくれます。普段話す言葉で答えてください。

黒い画面が好きな人は、second-brain の中で claude と打つだけです。Codexでも同じフォルダで動きます（CLAUDE.md を AGENTS.md という名前でコピー）。

動画のステップ1〜3で、もう箱を作った人へ

自分の second-brain に、このキットの memory/・staff/・inbox/ の3フォルダをコピーしてください。CLAUDE.md は、キットの「フォルダの地図」と「会話の終わりに」の2ブロックを自分の案内板へ足せば同じになります。about-me.md は自分のを残してください。

中身

場所何か
CLAUDE.md案内板。Claude Codeが起動時に必ず読む1枚（24行）
about-me.md自分のこと。雛形のままだと、AIが5つ質問して書き直す
memory/cases/案件カード。1案件1ファイル。「要約・いまやっていること・次の一手・待っていること」。いまの状態を上書き
memory/daily/日誌。1日1ファイル。起きたことを追記
staff/writer/AI社員1人目。_RULE.md（役割と読む順番）・skills/x-post/SKILL.md（手順書）・output/（成果物）
inbox/未整理の置き場

「状態（カード＝上書き）」と「物語（日誌＝追記）」を分けるのが、この箱が忘れない理由です。自分は一度、日誌を1つのファイルに書き続けて、多い日は1日15万字になり、AIが読み切れなくなって作り直しました。これは、その作り直した後の形です。

自分の箱に合わせて、AIに作らせたい方へ

キットを使わず、いま持っているフォルダに合わせて作らせる「貼るだけの文」です。Claude Code（Codexでも可）に貼ると、5つ質問してから、案内板・カードの雛形・AI社員1人目をその人向けに作ります。

貼るだけの文を開く
このフォルダを、自分の「第2の脳」にします。新しい会話でも「昨日の続き」が通じる箱にするのが目的です。
作業の前に、次の5つを1つずつ質問してください（まとめて聞かない）。
①仕事 ②役割（自分がやること／AIに任せたいこと） ③今やっていること（案件を2〜3個） ④大事にしている判断 ⑤苦手なこと

答えが揃ったら、次の順で作ってください。
1. about-me.md … 5つの答えを、本人の言葉遣いのまま20行以内でまとめる。
2. CLAUDE.md … フォルダの一番上に置く案内板。中身は3つだけ。
   ①「最初に about-me.md を読む」と1行
   ②返事のルール3つ（日本語で・結論から・専門用語は言い換える）
   ③フォルダの地図：memory（状態と日誌）／staff（AI社員）／inbox（未整理）の3つと、どこに何を入れるかを1行ずつ
   最後に「会話の終わりに、memory/cases の該当カードと memory/daily を更新する」と1行。全部で40行以内。
3. memory/cases/ … ③で聞いた案件を1件1ファイルで。見出しは「要約」「いまやっていること」「次の一手」「待っていること」の4つ。
4. memory/daily/ … 今日の日付のファイルを作り、今日の会話を3行で書く。
5. staff/writer/_RULE.md … 「役割：自分の代わりにXの投稿を書く担当」「読む順番：about-me.md → memory/cases の関係するカード → skills の手順書」「成果物の置き場：staff/writer/output/」の3つ。
6. staff/writer/skills/x-post/SKILL.md … Xの投稿を書く手順を5ステップで（素材を集める・切り口を決める・3案書く・about-me の言葉遣いに合わせる・output に保存する）。
7. inbox/README.md … 「未整理の物を置く場所。週1回、片づけてと頼む」と2行。
8. CLAUDE.md の地図に staff/writer を1行足す。

守ること：
・パスワード・APIキー・お客さんの実名は、どのファイルにも書かない（必要なら「A社」のように伏せる）
・すでに同じ名前のファイルがある時は、上書きせずに中身を見せて、どう直すか聞く
・全部できたら、作ったファイルの一覧を出して、最後に「新しい会話を開いて『昨日の続き、何だっけ』と聞いてみてください」と伝える
