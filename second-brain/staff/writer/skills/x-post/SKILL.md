# X投稿を書く手順（5ステップ）

1. **素材を集める**
   `memory/cases/` と `memory/daily/` から、今日・今週に実際に起きたことを拾う。無ければ本人に「今日いちばん印象に残ったことは何ですか」と1つだけ聞く。
2. **切り口を決める**
   読む人が持ち帰れる物を1つに絞る。道具の名前・手順・数字・失敗と直し方のどれか。考え方や心構えだけの投稿にしない。
3. **3案書く**
   それぞれ140字前後。1行目で結論。案ごとに切り口を変える（事実→手順／失敗→直し方／数字→理由）。
4. **about-me の言葉遣いに合わせる**
   `about-me.md` にある口調・一人称・よく使う言い回しに揃える。本人が言わない言葉は使わない。
5. **output に保存する**
   `staff/writer/output/YYYY-MM-DD_題名.md` に3案を保存し、本人には「どれを出しますか」と1行で聞く。
