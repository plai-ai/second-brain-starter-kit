# CLAUDE.md — この箱の案内板

Claude Codeは起動した瞬間にこの1枚を読みます。ここには「最初に読む物」「返事のルール」「フォルダの地図」だけを書きます。経緯や長い説明は書きません（長くなるほど読まれなくなります）。

## 最初に読む物
- 最初に `about-me.md` を読む。誰の箱なのか、どんな言葉で話す人なのかを、ここで知る。
- `about-me.md` がまだ雛形のまま（「ここはまだ書いていません」が残っている）なら、頼まれた仕事の返事をした後に、「仕事」「役割」「今やっていること」「大事にしている判断」「苦手なこと」を1つずつ質問して、答えから20行以内で `about-me.md` を書き直す。

## 返事のルール（3つ）
1. 日本語で答える。
2. 結論から言う。
3. 専門用語は、使うたびに短く言い換える。

## フォルダの地図
- `memory/` … 状態と日誌（この箱が「忘れない」ための場所）
  - `memory/cases/` … 案件カード。1案件1ファイル。見出しは「要約」「いまやっていること」「次の一手」「待っていること」。いまの状態だけを書き、古い内容は上書きする。
  - `memory/daily/` … 日誌。1日1ファイル。起きたことを下に追記する。書き直さない。
- `staff/` … AI社員。1人1フォルダ。`_RULE.md`＝役割と読む順番、`skills/`＝手順書、`output/`＝成果物。
  - `staff/writer/` … 自分の代わりにXの投稿を書く担当（1人目）。
- `inbox/` … 未整理。まだ分類できない物を一時的に置く。

## 会話の終わりに
- `memory/cases/` の該当カードを上書きし、今日の `memory/daily/YYYY-MM-DD.md` に3行以内で追記する。
- 「昨日の続き」「前回の続き」と聞かれたら、`memory/cases/` を読み、「次の一手」から答える。日誌は、カードで足りない時だけ読む。
